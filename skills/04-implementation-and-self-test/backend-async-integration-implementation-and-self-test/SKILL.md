# 后端异步与集成实现自测

实现可重复处理、可恢复和可观测的异步任务及外部依赖交互。同步 API 使用对应 API SKILL；本 SKILL 不假设消息恰好一次，也不在未授权情况下调用生产依赖。

## 输入

- 验收标准、事件/任务/外部接口契约、投递语义、顺序要求、风险等级和恢复策略。
- 队列/调度器约定、超时重试、死信/补偿、凭据和遥测规范。

## 工作方式

1. 明确生产者、消费者、所有者、schema 版本、分区/顺序和投递保证；把重复、延迟、乱序和丢失视为需显式处理的条件。
2. 设计幂等消费、去重、重试退避、超时、死信和人工重放边界；外部副作用须防止重复执行并保留可追踪标识。
3. 处理部分成功、下游限流、凭据过期和任务中断后的恢复；补偿动作必须有权限边界和停止条件。
4. 添加生产/消费、任务和适配器测试，覆盖重复、乱序、毒消息、超时、重试耗尽、重启和外部错误；测试替身须保持契约语义。
5. 补齐积压、延迟、成功/失败/重试/死信指标及关联日志/追踪，避免在消息和日志中传播非必要敏感数据。

## 输出格式

```markdown
## 后端异步与集成实现自测记录
- 生产者/消费者、任务与依赖边界：
- 契约版本、投递和顺序语义：
- 幂等、去重、重试、死信与补偿：
- 外部副作用和敏感数据处理：
- 自动化测试与遥测：
- 未覆盖项及集成/韧性验证需求：
```

## 本节点与后续边界

按[阶段04门槛](../../../docs/workflows/04-implementation-and-self-test.md)按批准范围/风险选择行为检查，保留项目必过集合；轻量文案不强加无意义单测。下列专项路由只承接原已规划后续项，本阶段必需构建/行为/真实依赖/恢复检查不能因缺环境延期。本技能输出限定领域结果及当前版本/环境/原始证据，整体由协调层与共享本地验证/交接核对；缺项可Draft协作，不代表正式交接资格。

## 停止条件

- 当重复与失败语义有测试，任务可恢复且关键遥测齐备时，交给后端协调层和本地质量验证。
- 真实 broker/调度器/下游兼容交给契约集成验证，故障恢复交给 `backend-resilience-recovery-validation`。
- 投递保证、数据所有权或补偿责任不明确时回流方案设计，不以无限重试掩盖缺口。
