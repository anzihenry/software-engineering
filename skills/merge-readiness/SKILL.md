# 合入就绪确认

对合入前的必要证据进行最终一致性检查，避免旧的成功结果、未解决反馈或未记录豁免随代码进入目标分支。此 SKILL 只给出结论，不自行合并代码或批准例外。

## 输入

- 当前 PR 提交和目标分支状态、CI 门禁结论、评审结论、系统验证报告。
- 项目合入规则、风险等级、未决事项和任何豁免记录。

## 工作方式

1. 确认所有证据都对应当前提交和目标分支；实质修改、冲突解决或目标分支重大变化后，识别需要重跑或复审的项目。
2. 核对必需 CI 门禁、审批数量/角色、系统验证、高风险专项评审和文档/迁移准备是否满足项目规则。
3. 确认阻塞性评审意见已解决，非阻塞反馈有明确处理结论，且代码、描述和发布预案仍保持一致。
4. 核对豁免的授权、范围、到期和补救计划，确保豁免没有覆盖未被授权的风险。
5. 记录可合入、条件不满足或需重验的结论；在阻塞时指出最小的解阻动作和责任人。

## 输出格式

```markdown
## 合入就绪确认
- 当前提交、目标分支与检查时间：
- 必需 CI / 评审 / 系统验证 / 专项审批状态：
- 已解决与未解决反馈：
- 豁免及其授权、到期和补救计划：
- 冲突、分支新鲜度和重验要求：
- 结论：可合入 | 阻塞 | 需重跑/复审
- 最小后续动作与责任人：
```

## 停止条件

- 当结论、证据对应关系和剩余事项清晰时结束，交给项目既有的合并机制。
- 任何必需检查、审批、验证或授权豁免缺失时，结论为阻塞或需重验。
- 不在本 SKILL 中执行合并、变更分支保护或自行批准风险例外。
