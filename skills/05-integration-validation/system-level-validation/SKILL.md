# 系统级验证

验证单元或组件检查无法充分覆盖的跨边界行为，并说明所得结论的适用范围。此 SKILL 不将测试环境的结果无条件外推为生产结论，也不执行生产发布。

## 输入

- 验证策略、需求/非功能要求、风险等级、PR、契约与迁移说明。
- 可用集成、预发布或隔离测试环境，依赖状态和生产基线（如有）。

## 工作方式

1. 读取[阶段05端到端底线](../../../docs/workflows/05-integration-validation.md#每次功能合入的端到端底线)及批准验收/风险/实际变更，确定核心、本次变更和适用风险专项集合。核心与本次集合每次功能合入前、合入main后均实际执行，重叠可去重但不能删判据；领域按风险组合，不要求全部专项。
2. 为用例关联稳定ID、验收/风险、环境/数据初态/依赖版本、可观察结果/关键不变量、维护人、失败入口和节点。端到端从真实业务入口经过适用内部界面/服务/存储/消息到最终结果；后端/CLI不硬造UI，组件/API单测或全mock不能替代。异步等待明确完成条件和合理超时，不能凭固定sleep通过。
3. 真实外部测试环境或替身记录授权/契约/替代范围/未验证项；替身覆盖关键变更风险则该风险仍未通过。缺环境blocked/not-run，不能NA。环境准备/构建可复用但核对版本/初态，独立并行隔离数据、账号和资源，结束安全清理自己创建的资源并保全原始证据。
4. 合入前绑定当前head/base及实际所测集成源码/构建，合入后绑定真实main合入SHA；保存命令/人工步骤、时间及时区、执行者、退出码、原始结果/报告摘要/局限。按[候选及连续合入规则](../../../docs/workflows/05-integration-validation.md#候选证据与连续合入)逐次关联A/B，取消/超时补跑指定对象，更晚main绿不自动替代，包含代码不证明逐项行为覆盖。
5. 执行/核对完整集合和关键失败/权限/兼容/恢复；失败保留首次和全部重试。隔离不稳定必需用例无有效同判据替代仍阻塞；仅在确认需求/契约或测试缺陷依据后修订断言，不降低预算或删测制造通过。支持条件/规模/浏览器/设备局限如实，不外推生产。
6. 变化影响证据后按范围重验，难界定则扩大；04证据/未变专项可按规则引用，不能免合入前后端到端及最新head CI。合入后失败暂停失败版本发布，按授权修复/回退并验证处置后的完整路径和数据；回退恢复基线不等于原功能成功。结果给PR编排和既有交接主记录，不复制一套状态。

## 输出格式

```markdown
## 系统级验证报告
| 要求/风险 | 场景与环境 | 证据/指标 | 结果 | 生产适用限制 |
| --- | --- | --- | --- | --- |

- 依赖与环境差异：
- 失败、缺陷或回流建议：
- 发布后需要继续观察的信号：
- 总结：通过 | 有条件通过 | 阻塞 | 环境不可信
```

## 停止条件

- 当前节点完整必需集合实际通过、对象和证据有效才给本节点通过；限制写清不能替代必需项。合入前交merge-readiness，合入后结果交PR编排核对05收口；合入后未执行不能提前填通过。
- 当失败指向实现、设计或契约问题时，回流相应阶段；当环境不可信时，停止把结果作为发布依据。
- 不因“难以搭建环境”而自动放弃高风险验证。

## 场景执行与机器报告

按[领域执行契约](../../../docs/domain-validation.md)盘点完整要求、适用性、支持矩阵与受控策略；实际场景和原始报告绑定当前候选。schema 1 读取器只核对一致性，旧 Markdown 继续独立人工审查；缺适用专项、原始执行、批准基线或必要辅助技术保持阻塞，不能从其他成功报告推导通过。
