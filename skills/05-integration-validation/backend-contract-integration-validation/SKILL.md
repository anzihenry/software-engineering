# 后端契约与集成验证

验证服务与真实调用方、消息系统和外部依赖按约定协同工作，并界定版本兼容范围。此 SKILL 不替代跨产品完整用户旅程或生产调用。

## 输入

- API/事件契约、调用方/依赖版本、风险等级、自测记录和待验证构建。
- 集成环境、认证配置、代表性数据、兼容窗口及协议观测手段。

## 工作方式

1. 建立提供方、消费者、协议、schema 和版本矩阵，标明必测组合与已批准的不支持范围。
2. 使用真实序列化、传输和认证链路验证正常、边界、错误、超时、分页及适用的流式行为。
3. 验证新增/缺失/未知字段、枚举扩展、默认值、顺序和重复消息等兼容场景，覆盖新旧调用方与提供方组合。
4. 对外部依赖检查限流、错误映射、超时和重试契约；测试环境替身与真实服务差异必须显式记录。
5. 将结果映射到契约和调用方，区分实现缺陷、契约破坏、版本不支持与环境失败。

## 输出格式

```markdown
## 后端契约与集成验证报告
| 契约/调用方 | 协议与版本组合 | 场景 | 证据 | 结果 |
| --- | --- | --- | --- | --- |

- 序列化、认证和错误语义结论：
- 前后兼容与调用方影响：
- 外部依赖及替身差异：
- 未覆盖组合及影响：
- 总结：通过 | 有条件通过 | 阻塞 | 环境不可信
```

## 停止条件

- 当高风险契约和必需版本组合已有证据时，将结果交给 `backend-validation`。
- API/事件实现问题回流对应开发；契约设计缺口回流方案与计划。
- 关键消费者或真实协议无法验证时，不以单元测试替身给出无条件通过结论。
