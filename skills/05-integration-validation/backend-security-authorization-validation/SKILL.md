# 后端安全与授权验证

验证应用层信任边界和安全控制在负向场景下成立。此 SKILL 不替代威胁建模、专业渗透测试、安全/合规审批或漏洞例外授权。

## 输入

- 授权模型、资源所有权/租户边界、数据分类、威胁模型、风险等级和待验证构建。
- 认证环境、测试身份/角色、接口与依赖清单、安全日志和速率/配额策略。

## 工作方式

1. 建立主体、角色/属性、动作、资源和租户矩阵，识别匿名、低权限、跨所有者、跨租户及已撤销身份场景。
2. 使用真实入口验证认证绕过、对象级/功能级授权、字段级敏感数据和默认拒绝；直接修改标识符或请求字段不得突破服务端裁决。
3. 验证输入大小/格式、注入、路径/URL、反序列化和外部请求等适用边界，确认错误不泄露密钥、内部拓扑或敏感记录。
4. 检查凭据、token、Cookie/会话、服务身份和密钥轮换/过期行为，以及日志、指标、缓存和消息中的敏感数据最小化。
5. 验证速率限制、配额和高成本操作的滥用控制及安全审计信号；测试仅使用授权账号、隔离数据和明确目标。

## 停止条件

- 当高风险授权和信任边界已有负向证据且缺口已处置时，将结果交给 `backend-validation`。
- 应用实现问题回流 API 或对应开发；威胁模型、合规或高风险漏洞交给有权限的安全负责人。
- 未经授权不扩大扫描目标、不使用真实用户敏感数据，也不自行接受安全风险。
