# 发布健康评估

按[健康与恢复契约](../../../docs/workflows/06-release-and-change-management.md#健康判定与恢复决策)判断当前批次，提供建议，不在未授权时执行处置。

## 证据与判定

- 先核对候选/制品、deployment、配置、批次/范围和预设标准；技术可用性/错误/延迟/资源/依赖、业务路径、SLO/告警/用户反馈、数据完整性与影响范围逐项有来源、基线/对照、阈值、统计窗口、最低有效样本和责任人。
- 核对观测有效性、延迟、采样变化、并发变更和外部事件；没有告警先确认监控正常。时间与必需样本均须满足；按事前约定可补探测/真实路径/延长观察，但不豁免必需真实样本，不临时放宽阈值。
- 每项保留原始值/时间/范围及判据，总体四类：通过（全部必需条件满足，支持授权内继续）；继续观察（时间/样本不足，保持范围）；异常（硬停止，暂停扩大并处置）；无法判定（缺失/冲突/不可信，暂停补证）。沿现有单项检查状态，不另造检查结果。
- 安全、数据损坏、核心路径失败或硬阈值立即停止，不等窗口或根因确定；归因未知不放行，也不盲目回滚。严重/扩大/超预案转07事故或安全隐私专项。

## 输出与停止

在[发布主记录](../../../templates/delivery/release-record.md)输出当前身份/范围、窗口及有效样本、来源/基线、逐项阈值与实际、数据质量/混杂因素、四类结论、建议和授权/责任/下一步。只有通过支持扩大，其他状态维持范围或暂停；恢复选择交负责人和 `release-recovery-execution`，部署job成功不足以形成健康结论。

## 隔离本地渠道参考

已明确授权的合成本地渠道按[本地交付契约](../../../docs/local-delivery-channel.md)记录制品、实际进程与应用路径、失败停止/恢复/取消，使用[双语渠道报告](../../../templates/documentation/local-delivery-channel.md)。其local-rehearsal结论不关闭本技能正式候选/平台/生产门槛，不改变第二层分发或写权限；其他渠道仍须补真实身份/保护/授权与独立证据。
