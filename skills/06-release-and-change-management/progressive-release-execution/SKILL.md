# 渐进发布执行

按[批次与中断契约](../../../docs/workflows/06-release-and-change-management.md#批次执行互斥与中断)执行已有授权，记录到[发布主记录](../../../templates/delivery/release-record.md)。不自行批准越界动作或省略停止条件。

## 输入与执行

需当前就绪passed、有效单次/分段/策略授权，以及候选、目标现场和每批预案。批次写起始状态/目标范围、制品配置/迁移、顺序、验证/观察/样本、超时/停止/恢复和责任。条件Go不是执行许可。

1. 每批前核对候选与授权仍有效、环境/依赖符合预案、前一批已满足推进条件。有效授权已覆盖的后续批次按条件推进，无需重复请示。
2. 确认可能冲突的部署、配置、开关和迁移互斥覆盖部署及观察期；并行须隔离依据。单job production concurrency不能替代跨workflow协调，不自动取消正在执行的生产任务。紧急介入先暂停原发布并保存现场。
3. 提升指定同一制品至一个批次，不临时重建或夹带改动；记录操作者/授权、时区起止、命令/run/deployment、输入和实际结果。
4. 核对实际落地版本/摘要、配置迁移及覆盖范围，在真实目标环境执行必需关键路径、数据和冒烟验证；05成功不替代落地验证。
5. 交 `release-health-assessment` 核对时间与有效样本及全部必需指标，再按授权继续、观察、暂停或恢复。达到硬停止立即停止扩大，恢复交 `release-recovery-execution`。

## 中断与部分成功

超时、断线、取消先记结果待确认，核实完成/仍执行/未执行目标、版本分布及数据/外部副作用，再决定安全重试、补偿或续跑；不可重复步骤先对账。续跑新建关联执行记录，保留首次结果，不把取消当未落地。

部分成功默认暂停扩大，记录混合版本范围/影响、兼容依据、期限和处置；不以多数成功掩盖失败目标。恢复环境后候选/授权仍有效且现场重验通过才续跑，内容/范围变化先刷新候选记录、验证和批准。

## 输出与停止

输出每批原始操作及实际落地/验证/观察、推进决定、未决状态/责任/复查时间。缺授权、预案、可靠观测、前一批通过或实际状态未知不继续；达到目标后交收口，不把执行完成直接记成功交付。

## 隔离本地渠道参考

已明确授权的合成本地渠道按[本地交付契约](../../../docs/local-delivery-channel.md)记录制品、实际进程与应用路径、失败停止/恢复/取消，使用[双语渠道报告](../../../templates/documentation/local-delivery-channel.md)。其local-rehearsal结论不关闭本技能正式候选/平台/生产门槛，不改变第二层分发或写权限；其他渠道仍须补真实身份/保护/授权与独立证据。
