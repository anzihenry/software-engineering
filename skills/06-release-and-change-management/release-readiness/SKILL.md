# 发布就绪检查

按[质量门禁](../../../docs/quality-gates.md)及[发布批准契约](../../../docs/workflows/06-release-and-change-management.md#发布批准与有效期)形成建议，不批准生产或执行部署/环境修改/恢复。

## 核对范围

1. 候选ID/修订、源码/完整组合、制品摘要、构建/证据、配置/开关/迁移、目标渠道和恢复目标一致；必需候选验证及适用专项通过。
2. 环境/依赖健康、预演与生产差异明确，凭据/Environment实际保护、值守/沟通、批次和覆盖部署及观察期的互斥可用；不能预演风险明确保留，关键未知不放行。
3. 技术/业务/数据/范围指标有来源/基线/阈值、时间窗口/最低有效样本和责任；监控告警可用，关键路径验证及恢复方法可执行。支持版本/兼容窗口、启用/迁移顺序和破坏性清理条件明确。
4. 单独核对有权人类批准或预批准策略的身份来源、候选、环境/渠道/动作/范围、批次、有效窗口/到期、条件机制、停止/恢复与值守。平台审批不可用保留实际人工决定，不虚构强制；触发按钮不自动代表完整授权。
5. 候选/范围变化、窗口到期、前置能力失效、新阻塞或撤销/并发冲突使受影响推进暂停。无影响文字修正有理由可保留批准。有效边界内不用重复批准；预授权条件由指定机制核验后重判就绪passed才可自动推进，明确要求再次确认则仍需确认。

## 文档与结果

正式发布前必须有非作者 `documentation-delivery-validation` 对当前候选的通过记录，核对版本说明、适用兼容/升级指南及同一产物证据，使用[文档交付检查](../../../templates/documentation/delivery-check.md)。必需文档/译文/证据缺失只能阻塞，不用一般例外或条件Go豁免。

在[发布主记录](../../../templates/delivery/release-record.md)分别输出：候选/目标及风险、逐项结果和证据、环境/预演/观测/恢复、就绪passed/conditional/blocked（兼容Go/条件Go/No-Go措辞）、独立授权批准/待条件满足/拒绝撤销及来源、缺口责任和核验方式。条件未完成和重验前不得执行；就绪通过不产生授权。关键授权、环境、观测、恢复或值守缺失保持停止，不把CI或部署命令可用当发布就绪。

## 隔离本地渠道参考

已明确授权的合成本地渠道按[本地交付契约](../../../docs/local-delivery-channel.md)记录制品、实际进程与应用路径、失败停止/恢复/取消，使用[双语渠道报告](../../../templates/documentation/local-delivery-channel.md)。其local-rehearsal结论不关闭本技能正式候选/平台/生产门槛，不改变第二层分发或写权限；其他渠道仍须补真实身份/保护/授权与独立证据。
