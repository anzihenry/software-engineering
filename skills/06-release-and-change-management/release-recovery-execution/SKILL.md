# 发布恢复执行

按[健康与恢复契约](../../../docs/workflows/06-release-and-change-management.md#健康判定与恢复决策)控制用户影响，消费现有恢复授权；不自行选择未授权破坏性操作。

## 执行与验证

1. 确认停止扩大，保全当前候选/版本/制品、配置/迁移、范围/用户影响、异常及授权。严重或扩大/超预案转07事故，安全隐私走专项。
2. 核对恢复路径已预演及适用性证据；未预演部分保留风险，按既有门禁决定，不自行放行关键未知。按可逆性、预计恢复时间、数据风险、协议/依赖/旧版本兼容及授权选择最小路径：关开关/停止分发、旧制品配置、数据补偿恢复或已验证前滚。不能假定代码回滚恢复数据；数据删除、不可逆迁移或扩大影响等未覆盖操作另取明确授权，已覆盖安全步骤无需重复请示。
3. 一次一步，协调部署/观察期互斥，记录操作者/时区时间、输入输出版本、命令/run/deployment及原始结果。超时/取消先对账实际状态与副作用，不盲重试。
4. 验实际版本/摘要、配置开关/迁移、数据不变量和外部副作用、关键用户路径及稳定观察窗口。命令成功不足；部分恢复记录剩余用户/数据影响并保持处置，连续失败/风险不明停止升级。
5. 客户端无法即时撤回时用兼容服务、远程开关、停止扩大发布或前滚，记录仍安装受影响版本的范围。前滚生成新候选并关联验证/授权，不覆盖旧失败。
6. 恢复后明确原发布终止、暂停或满足重验/有效授权后继续。旧基线恢复记失败已恢复，不记原功能成功；结果交 `release-closure` 或事故负责人显式接收。

## 输出与停止

在[发布主记录](../../../templates/delivery/release-record.md)输出触发/授权、起始与恢复目标、逐步实际证据、数据/用户/稳定窗、结论已恢复/部分恢复/前滚中/阻塞/转事故、剩余影响及责任/下一动作/复查。预案不适用或授权不足停对应动作；不擅自删除数据、覆盖制品、移动标签或管理员旁路。恢复验证完成后再交接，事故持续责任不因发布结案关闭。

## 隔离本地渠道参考

已明确授权的合成本地渠道按[本地交付契约](../../../docs/local-delivery-channel.md)记录制品、实际进程与应用路径、失败停止/恢复/取消，使用[双语渠道报告](../../../templates/documentation/local-delivery-channel.md)。其local-rehearsal结论不关闭本技能正式候选/平台/生产门槛，不改变第二层分发或写权限；其他渠道仍须补真实身份/保护/授权与独立证据。
