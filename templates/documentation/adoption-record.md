# 项目采用验收记录模板

[English](adoption-record.en.md)

- record_id、record_status、owner、decision_authority、risk_level、related_records、created_at、updated_at：
- source_version：harness 仓库/完整知识提交、工具提交或摘要、目标 head/base/merge、环境与配置：
- 根/全局/目录入口清单与覆盖判断、技能与规范路径、适用 references、责任和任务唯一事实来源：
- 实际命令、版本、原始报告、未执行项及原因：
- 独立 Agent 实际任务、身份/另起上下文、工具读取与执行轨迹、问题/修正/复核：
- 真实 GitHub 身份/写权限、可信记录来源、PR、CI/App、规则回读与违规合入阻断：
- 正反例、各自当前对象、结果与原始证据：
- 本地结论、行为观察结论、远端结论、适用限制及不适用依据分别记录：
- 遗留迁移/阻塞、责任、解阻任务与复验条件：

按[采用规范](../../docs/harness-adoption.md)逐项验收；不凭“已加载”、文件存在或本地成功声称全项目采用/远端强制，必需缺口不豁免。
