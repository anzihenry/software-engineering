# 阶段 05：集成验证优化计划

## 授权、基线与完成定义

用户已确认全部讨论并授权按四包实施，每包检查、非作者独立复核后单独提交。阶段04已通过PR47合入main；本轮fetch后从 `ee55b63d9bf44f5d86671828df4800a754b08c92` 建立 `codex/phase05-integration-validation`，初始工作区干净、无其他worktree或任务分支。先单独提交正式计划，再依次实施。当前交付本地任务分支，后续推送/合入按实际授权处理。

完成定义：对明确的集成候选完成独立评审及全部适用验证，取得有当前证据支持的合入决定，经授权通过项目机制合入main；实际合入版本的必需端到端验证通过，形成可追溯的阶段06交接。正式接收、可合入、实际合入和本阶段完成分别判断；接收不是通过，可合入不是合并授权，合入不是发布批准。

本轮是harness执行资产维护，保持skills/workflows/templates组织、既有字段/状态及高风险规则，不自动给所有目标项目部署CI，也不把本地合成试用当成真实平台强制。既有阶段01–04、Swift最低6.4、Git/文档及质量门禁保留。

## 已确认执行契约

最低完成七项：04交接合格；按验收/实际变化/风险确认完整验证集合；当前候选必需CI实际通过；独立评审及必要复审通过；适用专项和合入前端到端通过；取得授权并受控合入；实际main版本合入后必需端到端通过且06交接完整。未合入可停在可合入；合入后验证未完成或失败保留已合入事实，但阶段05不完成，失败版本暂停发布。

每次功能合入前、合入main后均实际执行端到端。核心集合每次运行，本次变更集合覆盖功能、修复及受影响已有行为，风险专项按触发/节点执行；重叠用例可去重，不能删判据。定义真实业务入口到最终用户可见结果/关键数据不变量，后端/CLI不硬造界面，异步用明确业务完成条件及合理超时，不凭固定sleep成功。真实适用内部界面/服务/数据库/消息链路应组合验证；外部测试环境或替身写契约/替代范围，替身若覆盖关键变更风险就不能宣称该风险通过。

用例有稳定ID、验收/风险、环境/前置数据、依赖版本、判据、维护人、失败入口及执行节点。03规划、04补实施影响、05独立查漏；增删有依据，不因失败/难搭环境/运行慢而减少必需项。成本优化可按影响选择、并行隔离数据、复用环境准备/构建和低层细节测试；不减少每次合入前后端到端义务。隔离不稳定必需用例没有有效同判据替代证据仍阻塞。

独立评审六方面：范围/验收、实现调用路径/失败、契约/安全、测试充分性、运行/恢复、文档/证据。评审者实际读取需求/设计/diff及相关上下文，记录版本/范围/未覆盖/发现/复审条件；反馈分阻塞、待澄清、非阻塞改进、可选建议。关线程不证明解决；依规则/契约处理分歧，影响合入判断的疑问先澄清。直接参与修改后换非作者复核该范围；Agent不冒充人工批准或高风险专业决定。

CI核对完整期望集合和真实来源/对象，不只看出现的绿项。失败、取消、超时、未触发、错误跳过保留实际状态，不适用需规则和事实；缺环境不是不适用。保留首次及全部重试，不挑绿；旧基线失败不豁免必过项。实现回04、关键方案回03、业务验收回02；测试缺陷按确认依据修正仍能检错；环境所有者解阻；安全事件按事件流程。例外仅沿原质量门禁非强制范围，必过CI/文档/译文/证据/独立性/人类高风险决定不可豁免。

主记录复用交接/验证矩阵，一项要求对应适用依据、候选/环境/数据、实际结果、原始证据/摘要、责任和动作。证据绑定head/base及所测集成源码/构建，合入后绑定真实main SHA；版本、冲突、基线、依赖或测试变化重评影响并复验，未受影响有效评审/专项可按规则复用，不能代替最新head CI或每次功能合入前后端到端。检查期间变化需明确实际所测对象，不能识别则stale。

连续合入A/B各自关联精确SHA、用例、结果和责任，不能仅以更晚B绿替A；多个变更共用执行记录时必须明确实际所测版本/包含合入、每项完整用例/判据和覆盖依据，不免除任一次合入义务。允许取消被新提交替代的PR诊断运行，不能静默取消合入后必需端到端；取消必须补跑指定对象并记录。来源/内容可能合并不等于语义覆盖。基线失败先定位/限制影响，公共能力或影响未知扩大停止范围；已隔离无关授权工作可以继续。

合入后失败闭环：保全证据、判断影响、暂停失败版本发布、按授权修复或回退、验证处置版本、记录结果。代码回退不等于数据/外部副作用恢复。修复通过才交付原功能；回退恢复基线仅故障处置完成，原功能未交付，另有后续/停止决定，不补记功能成功。沿七状态，已合入仅Git事实；本节点执行状态/完成结论另记，不新造第二套变更状态。

交06七项：批准范围/验收及实际交付、PR/源码/合入SHA及已有制品摘要、CI/独立/专项/前后端到端证据、失败修复回退/未决事项、发布兼容/配置/迁移依赖、观测/恢复/文档译文及后续任务、实际交出/接收/责任/时间。06固定候选、验环境和生产权限，不由main验证自动得到候选verified或生产Go。

## 验收场景与真实执行

至少覆盖：轻量文案仍前后端到端；组件/API绿而保存重登丢数据；跨租户负例；缺真机/依赖；必需检查未触发/取消/超时/跳过；首次失败重试绿；旧基线失败；评审后代码/基线改变；连续合入A/B；合入后执行被取消；合入后失败修复；回退仅恢复基线；隔离必需用例；mock替代关键风险；main成功不授权生产；评审者参与修复换人；反馈线程关闭但错误仍在；证据可复用和必需前后执行不可替代。

在临时隔离合成Git项目真实运行本地业务入口→实际存储→重启读取的端到端，保留候选/合入前后SHA、源码/构建/数据/执行摘要与原始命令/时间/退出码；至少实际检出合入后故障、完成修复和回退，并演示A/B精确对象责任及取消补跑记录。仅本机合成数据、现有工具和回环网络（需要时），不安装依赖、不操作真实远端/生产。可用CLI真实入口，无实际浏览器/移动验证时明确桌面范围；不能以单测或全mock冒充真实链路。必要可复验代码/数据说明/脚本保全在证据中，原失败不覆盖。观察到规则缺口修正后重验受影响范围。
