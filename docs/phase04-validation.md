## 问题、修正与复验

计划初次独立评审发现 README 新行前空行断开导航表格，作者修正后同步catalog；中间 plan-r2 如实保留过期catalog导致的机械失败，plan-r3全检查和独立复核通过。旧失败日志未被覆盖。第一包后未观察到需修正的规则缺口时，不额外堆积普遍规则。

独立试用未发现需新增规则的决策缺口。D08第二次运行改变了受控外部依赖fixture，演示真实失败与后续绿测都保留，不能据此证明同条件随机抖动或稳定性；D10故意保留失败候选，说明证据失效/阻塞决定正确，不是本仓库检查失败。228项产物完整性核对只检查日志/对象绑定，不是额外产品验收测试。

试用启动发现命令早于结构化记录器，无法回填其精确起止时间；原工具轨迹未改写，正式Git/Python实测均有完整命令/时间/退出和原始输出，允许材料也以结构化命令重读留存。该限制不冒充完整起始轨迹或外部采用证明。
