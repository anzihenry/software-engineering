# GitHub Lifecycle Automation v1.2.0

本版本让跨项目自动化从“可以安装”进入“可以安全升级并由真实 GitHub 证据验证”的阶段，不增加新的生命周期功能范围。

## 主要变化

- 新增 `.github/lifecycle-installation.json`，记录固定来源、manifest schema、profile、adapter 和托管文件摘要。
- 新增三方 `upgrade` 计划，仅自动处理 `create`、`safe-update` 和 `unchanged`；本地修改、冲突、符号链接和计划后变化会停止。
- 保留上游移除文件，不执行隐式删除；写入失败回滚本次文件变化。
- 建立真实 GitHub canary，验证四种代表 adapter/profile、八项稳定 checks、仓库治理和 `v1.1.0` 真实升级链路。
- 增加快速开始、版本兼容矩阵、升级/恢复指南、CHANGELOG 和版本化 Release notes。
