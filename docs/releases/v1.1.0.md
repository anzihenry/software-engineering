# GitHub Lifecycle Automation v1.1.0

本版本改善成熟项目的渐进采用体验：安装范围与语言实现解耦，并用完整 4 × 4 矩阵验证组合契约。

## 主要变化

- 明确研发知识、GitHub 生命周期自动化、跨项目安装治理三层边界。
- 增加 `governance`、`incident`、`release`、`full` 四种安装 profile。
- 增加 Python、Node、Swift、Go adapter，以及保留既有 CI 的 external/custom 路径。
- 增加受限 Dependabot PR 验证，机器人更新仍需通过两项稳定检查。
- 增加 16 个 adapter × profile 的离线验收组合。

## 兼容与升级

`v1.1.0` 使用 manifest schema 3，旧 schema 1/2 仍可作为 `full` bundle 读取。本版本尚未包含自动 `upgrade` 命令；升级到后续版本时，应由新版本工具读取固定的 `v1.1.0` 发布包并建立 installation record。

本版本不会正式发布目标项目、部署、回滚、批准高风险变更或存储敏感事故内容。
