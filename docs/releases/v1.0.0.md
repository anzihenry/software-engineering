# GitHub Lifecycle Automation v1.0.0

首个稳定的可复用 GitHub 生命周期自动化包。

## 主要能力

- 结构化 PR policy 与按风险增加的证据门禁。
- 确定性 Draft Release 候选准备。
- 普通事故流转、安全/隐私受限入口、复盘、改进行动和只读审计。
- 跨项目 `install`、只读 `doctor` 和证据 PR 约束的 `bootstrap`。

## 获取和核验

下载 `github-lifecycle.zip` 与 `github-lifecycle.zip.sha256`，使用 SHA-256 文件核验 ZIP，审查内容后再按文档执行。安装和 GitHub 引导默认 dry-run；实际写入要求精确确认字符串。
